# Black Hole Animation

A real-time, interactive black hole visualization built with pure WebGL and GLSL shaders. 

## Features

Gravitational lensing - Schwarzschild geodesic raymarching for realistic light bending
Accretion disk - Relativistically beamed, turbulent, and rotating with Doppler effects
Photon ring & corona - A thin, bright ring around the event horizon
Milky Way starfield - Procedurally generated galaxy with dust lanes, rifts, and a bright galactic bulge
Shooting meteors - Streaking meteors that move through the galaxy
Interactive controls - Drag with mouse or touch to orbit, scroll to zoom in and out
Mobile-friendly - Responsive and optimized for smaller screens
Minimal - No UI, buttons, or overlays, just the animation

## Clone and Run in VS Code

1. Clone the repo
   ```bash
   git clone https://github.com/arovex/interstellar-core.git

2. Run locally
Open blackhole.html directly in your browser (double-click it), or
Use the Live Server extension in VS Code (right-click blackhole.html → "Open with Live Server"). Live Server is recommended for best WebGL performance.

3. Usage
Drag with mouse/touch to orbit around the black hole. Use the scroll wheel (or pinch on mobile) to zoom in and out.
